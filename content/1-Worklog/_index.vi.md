**Trong trang này**, bạn sẽ tìm thấy toàn bộ nhật ký công việc ghi lại hành trình thực tập của tôi khi tham gia chương trình First Cloud Journey.

Chương trình được chia làm hai giai đoạn chính. Trong 6 tuần đầu, tôi tập trung nghiên cứu và làm chủ các kiến thức nền tảng của hệ sinh thái AWS. Từ tuần thứ 7 trở đi, tôi tham gia phát triển dự án thực tế **Wakan** với vai trò **AI Integration & QA/Data Engineer**.

**Giai đoạn 1: Khám phá và Làm chủ hệ sinh thái AWS**
* **Tuần 1:** [Khởi động, Dịch vụ cốt lõi (EC2, EBS), Console & AWS CLI và Quản lý chi phí](1.1-week1/)
* **Tuần 2:** [Hạ tầng mạng ảo Custom VPC, Phân lớp Subnet và Giám sát bảo mật với VPC Flow Logs](1.2-week2/)
* **Tuần 3:** [Kiến trúc High Availability, Bộ cân bằng tải ALB và Tự động co giãn hệ thống Auto Scaling](1.3-week3/)
* **Tuần 4:** [Quản trị lưu trữ Object với Amazon S3, Quản lý vòng đời Lifecycle và Mã hóa bảo mật với AWS KMS](1.4-week4/)
* **Tuần 5:** [Cơ sở dữ liệu đám mây (RDS Multi-AZ, DynamoDB) và Thiết lập API Serverless Backend (Lambda, API Gateway)](1.5-week5/)
* **Tuần 6:** [Giám sát hệ thống với Amazon CloudWatch, Truy vấn Log phân tích bằng Amazon Athena và Hoàn thiện Capstone Project](1.6-week6/)

**Giai đoạn 2: Phát triển dự án thực tế (Dự án Wakan)**
* **Tuần 7:** [Định hình Phạm vi Tính năng, Nghiên cứu External AI API & Nháp Prompt Template](1.7-week7/)
* **Tuần 8:** [Đồng bộ API Contract & Dựng khung Mã nguồn Lambda AI Processor](1.8-week8/)
* **Tuần 9:** [Hoàn thiện Prompt Template, Xử lý Logic Validate JSON & Xây dựng Bảng dữ liệu địa điểm Pro](1.9-week9/)
* **Tuần 10:** [Tích hợp Hệ thống Toàn diện (End-to-End Testing) & Kiểm thử Chất lượng AI Chống Ảo giác](1.10-week10/)
* **Tuần 11:** [Thiết lập Test Cases, Chạy Kiểm thử Toàn diện Unit & Integration Test](1.11-week11/)
* **Tuần 12:** [Đóng gói Sản phẩm, Quay Video Demo, Chuẩn bị Bộ Dữ liệu Dự phòng & Bảo vệ Dự án](1.12-week12/)
