**On this page**, you will find the complete worklog documenting my internship journey while participating in the First Cloud Journey program.

The program is divided into two main phases. During the first 6 weeks, I focused on researching and mastering the foundational knowledge of the AWS ecosystem. From week 7 onwards, I participated in the development of the real-world project **Wakan** in the role of **AI Integration & QA/Data Engineer**.

**Phase 1: Discovering and Mastering the AWS Ecosystem**
* **Week 1:** [Kick-off, Core Services (EC2, EBS), Console & AWS CLI, and Cost Management](1.1-week1/)
* **Week 2:** [Custom VPC Virtual Network Infrastructure, Subnet Tiering, and Security Monitoring with VPC Flow Logs](1.2-week2/)
* **Week 3:** [High Availability Architecture, ALB Load Balancer, and Auto Scaling System](1.3-week3/)
* **Week 4:** [Object Storage Administration with Amazon S3, Lifecycle Management, and Security Encryption with AWS KMS](1.4-week4/)
* **Week 5:** [Cloud Databases (RDS Multi-AZ, DynamoDB) and Serverless API Backend Setup (Lambda, API Gateway)](1.5-week5/)
* **Week 6:** [System Monitoring with Amazon CloudWatch, Log Analysis Queries using Amazon Athena, and Capstone Project Finalization](1.6-week6/)

**Phase 2: Real-world Project Development (Wakan Project)**
* **Week 7:** [Feature Scope Definition, External AI API Research & Prompt Template Drafting](1.7-week7/)
* **Week 8:** [API Contract Synchronization & Lambda AI Processor Code Framework Setup](1.8-week8/)
* **Week 9:** [Prompt Template Finalization, JSON Validation Logic Processing & Pro Location Dataset Building](1.9-week9/)
* **Week 10:** [Comprehensive System Integration (End-to-End Testing) & AI Quality Testing Against Hallucinations](1.10-week10/)
* **Week 11:** [Test Cases Setup, Comprehensive Unit & Integration Testing Execution](1.11-week11/)
* **Week 12:** [Product Packaging, Demo Video Recording, Backup Dataset Preparation & Project Defense](1.12-week12/)
